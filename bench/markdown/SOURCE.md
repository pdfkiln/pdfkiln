# Markdown corpus

Documents for `bench/markdown.ts` and for reviewing the Markdown style
sheet: real READMEs, and documents written for PDFKiln that hold what
those lack (math as chat assistants write it, alerts, a front matter, a
report in French). They are test data, never part of the packages.

| Document | What it holds | Source | License |
| --- | --- | --- | --- |
| `pdf-lib-readme.md` | A long README: 49 pages, 100 code blocks, tables, remote images | README of `@cantoo/pdf-lib` 2.11.1, https://github.com/cantoo-scribe/pdf-lib | MIT, Copyright (c) 2019 Andrew Dillon |
| `highlightjs-readme.md` | Code in many languages, badges, a table of contents | README of `highlight.js` 11.12.0, https://github.com/highlightjs/highlight.js | BSD-3-Clause, Copyright (c) 2006, Ivan Sagalaev |
| `katex-readme.md` | Raw HTML heading, badges, code | README of `katex` 0.19.1, https://github.com/KaTeX/KaTeX | MIT, Copyright (c) 2013-2020 Khan Academy and other contributors |
| `agent-report-fr.md` | A report as an assistant writes one, in French: front matter, alerts, tables of figures, math, SQL, task list, footnote, emoji | Written for PDFKiln | MIT, as PDFKiln |
| `math-chat.md` | `\(...\)`, `\[...\]`, `$...$`, `$$...$$`, in lists too; dollars that are prices; a formula in error | Written for PDFKiln | MIT, as PDFKiln |
| `github-readme.md` | A GitHub README: centered HTML logo and title, alerts, `<details>`, `<kbd>`, a forced page break, `<sub>` and `<sup>` | Written for PDFKiln; `images/logo.svg` too | MIT, as PDFKiln |

The READMEs are copied unchanged from the npm packages of the versions named,
which carry them with their license.
